通过openvpn的方式进入到内网中进行测试
 
1. 通过在终端中运行以下命令下载 OpenVPN： sudo apt install openvpn  
2. 找到您的 VPN 配置文件的完整路径（从[访问](https://tryhackme.com/access)页面下载），通常位于您的下载文件夹中。  
3. 使用以下命令使用您的 OpenVPN 文件： sudo openvpn /path-to-file/file-name.ovpn
